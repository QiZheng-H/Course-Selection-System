## 8. 演示数据边界

| 数据 | 来源 | 演示标记 |
|---|---|---|
| 培养方案（专业、总学分、模块学分、课程代码/名称/学分/必修选修/建议学期） | 官方培养计划 | `programs.source_*`，页面显示原文件/网址/页码 |
| 课程（courses） | 官方培养计划（仅官方给出课程号的 82 门） | 描述中注明官方来源；`is_demo = 0`。`department`（开课单位）**官方文件没有提供**，是演示元数据 |
| 教师（teachers） | 本项目模拟 | `is_demo = 1`，姓名为随机生成的演示姓名，院系标注“演示教师（模拟配置）” |
| 教学班时间 / 教室 / 容量 / 毕业预留（teaching_classes / class_sessions） | 本项目模拟 | `is_demo = 1`，note 以“【演示数据】”开头 |
| 学生账号与修读记录（students / student_course_records） | 本项目模拟 | `is_demo = 1`，`app_configs.demo_data_notice` 统一说明 |

演示学期默认 `2026-2027-1`（= 2024 级学生的 `三/1`）；
学生修读记录按“早于当前阶段的课程多数已通过、少数不及格，当前阶段课程不预置”生成，
以便 Agent 基于**官方方案 + 个人修读记录 + 本学期开课情况**给出规划。

## 9. 复核方式

```bash
# 查看官方来源与页码
sqlite3 server/data/course-selection.db \
  "SELECT code, name, grade, major, total_credits, version, source_url, source_pages FROM programs;"

# 核对某门课程
sqlite3 server/data/course-selection.db \
  "SELECT c.code, c.name, c.credits, cc.course_nature, cc.suggested_term
     FROM curriculum_courses cc JOIN courses c ON c.id = cc.course_id
    WHERE c.code = '12002920';"

# 页面对照：管理端“培养方案”页 / 学生端“培养方案”页
```

自动化回归测试见 [`server/tests/official-plan.test.ts`](../server/tests/official-plan.test.ts)：
核对课程代码/名称/学分/属性/建议学期抽样、模块学分要求、来源与页码、演示标记、
以及 Agent 的“本学期 / 补修 / 提前修读”判断。
