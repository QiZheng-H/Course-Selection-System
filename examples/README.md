# 示例导入文件

这些文件用于演示管理端的 **资料核对发布**（`POST /api/admin/imports`，表单字段 `file` + `kind`）。
导入只会生成“批次 + 校验报告”，确认无误后点 **发布** 才会写入正式数据。

| 文件 | 上传时选择的资料类型（kind） | 说明 |
|---|---|---|
| `课程导入示例.csv` | `courses` | 课程号 / 课程名称 / 学分 / 院系 / 课程类型 / 说明。**这 3 门是演示补充课程**（`DEMO1001`–`DEMO1003`），不属于官方培养计划 |
| `教学班导入示例.csv` | `classes` | 教学班号 / 课程号 / 容量 / 预留名额 / 教师 / 星期 / 节次 / 起止周 / 单双周 / 教室 / 学期 / 校区。教师、时间与容量属于演示模拟配置 |
| `修读记录导入示例.csv` | `records` | 学号 / 课程号 / 状态 / 学期 / 学分；状态支持 `passed`、`failed`、`in_progress`、`selected` 或对应中文。课程号使用**官方培养计划中的课程号** |
| `预分配导入示例.csv` | `preallocation` | 学号 / 教学班号 / 余量（余量 = 该教学班为管理员调整预留的空位） |

## 推荐演示顺序

1. 先导入 `课程导入示例.csv`（教学班示例依赖这些课程号，未找到的课程行会被跳过）。
2. 再导入 `教学班导入示例.csv`，可以在 **课程检索** 里看到新教学班与上课时段。
3. `修读记录导入示例.csv` 发布后，相关学生的 **修读记录** 会变成“需重新确认”（关键资料变化不静默删除已选课）。
4. `预分配导入示例.csv` 发布后在 **预分配与分配** 里点校验，可以看到“可落实 / 会失败”和调整余量的说明。
   教学班号取自演示数据自带的教学班（`202620271-xxx`）。

## 表头兼容

- 列名支持中英文写法（例如 `课程号` / `code`、`学分` / `credits`），大小写与空格差异会被忽略。
- CSV 支持逗号与全角逗号 `，`；也支持制表符分隔的文本。
- 除 CSV 外，还支持 XLSX 与文字型 DOCX / PDF；扫描件或复杂排版建议先转成 CSV。

## 与官方培养方案的关系（重要）

- 演示库里的**培养方案**（专业、总学分、模块学分要求、课程代码/名称/学分/必修选修/建议修读学年学期）
  来自学校官方发布的《上海理工大学本科培养计划（2024级）》上册，不是导入文件生成的。
  来源网址、页码与逐条核对见 [`docs/培养方案来源核对.md`](../docs/培养方案来源核对.md)。
- `修读记录导入示例.csv` 里的课程号必须是**官方培养计划中的课程号**（例如 `22000210` 高等数学 A(1)、
  `12002920` 数据结构、`12002050` 电路原理、`12003550` Web 应用开发）。
  如果导入的课程号在库里不存在，该行会报“课程号 XXX 不存在”，发布会被拒绝。
- `课程导入示例.csv` / `教学班导入示例.csv` 里的 `DEMO…` 是**演示补充课程**，用于演示导入流程，
  刻意不与官方课程号冲突；它们不代表培养计划内容。
- **教师、教学班时间与容量**属于本项目模拟配置（库内 `is_demo = 1`，界面标注“【演示数据】”），
  可以用这里的示例 CSV 覆盖或补充；这不影响培养方案本身。

## 与授权 / 保障的关系（重要）

- 导入文件**只产生资料**：课程、教学班、修读记录、预分配结果。它**不会**创建毕业兜底授权、
  课程替换授权，也不会替学生确认退换课。这些授权必须由**学生本人**在“结果与候补”页确认。
- `预分配导入示例.csv` 只生成“待落实”的预分配记录；要在“预分配与分配”页点 **落实预分配** 才会占用正式名额
  （不含毕业预留）。预分配发生在首轮之前，属于系统内部落实。
- 资料发布会生成新的资料版本并使旧版本失效；如果批次已经冻结，**关键资料变化后请重新冻结再试算**，
  否则发布时会因快照版本不一致被拒绝（`CONFLICT`）。
- 发布后的正确顺序：落实预分配 → 学生提交志愿 → 截止冻结 → 试算（后台任务）→ 处理异常 → 发布指定的试算结果。
