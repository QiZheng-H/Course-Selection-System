# 示例导入文件

这些文件用于演示管理端的 **资料核对发布**（`POST /api/admin/imports`，表单字段 `file` + `kind`）。
导入只会生成“批次 + 校验报告”，确认无误后点 **发布** 才会写入正式数据。

| 文件 | 上传时选择的资料类型（kind） | 说明 |
|---|---|---|
| `课程导入示例.csv` | `courses` | 课程号 / 课程名称 / 学分 / 院系 / 课程类型 / 说明 |
| `教学班导入示例.csv` | `classes` | 教学班号 / 课程号 / 容量 / 预留名额 / 教师 / 星期 / 节次 / 起止周 / 单双周 / 教室 / 学期 / 校区 |
| `修读记录导入示例.csv` | `records` | 学号 / 课程号 / 状态 / 学期 / 学分；状态支持 `passed`、`failed`、`in_progress`、`selected` 或对应中文 |
| `预分配导入示例.csv` | `preallocation` | 学号 / 教学班号 / 余量（余量 = 该教学班为管理员调整预留的空位） |

## 推荐演示顺序

1. 先导入 `课程导入示例.csv`（教学班示例依赖这些课程号，未找到的课程行会被跳过）。
2. 再导入 `教学班导入示例.csv`，可以在 **课程检索** 里看到新教学班与上课时段。
3. `修读记录导入示例.csv` 发布后，相关学生的 **修读记录** 会变成“需重新确认”（关键资料变化不静默删除已选课）。
4. `预分配导入示例.csv` 发布后在 **预分配与分配** 里点校验，可以看到“可落实 / 会失败”和调整余量的说明。

## 表头兼容

- 列名支持中英文写法（例如 `课程号` / `code`、`学分` / `credits`），大小写与空格差异会被忽略。
- CSV 支持逗号与全角逗号 `，`；也支持制表符分隔的文本。
- 除 CSV 外，还支持 XLSX 与文字型 DOCX / PDF；扫描件或复杂排版建议先转成 CSV。
